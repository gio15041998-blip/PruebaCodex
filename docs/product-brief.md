# Salud Perú — Especificación inicial

## Objetivo
Crear una aplicación web de orientación y seguimiento de salud para usuarios en Perú. No diagnostica ni prescribe; ofrece información educativa, señales de alarma y orientación para buscar atención profesional.

## Módulo inicial
- Registro e inicio de sesión con correo o Google.
- Perfil privado y consentimiento informado.
- Registro diario de síntomas, temperatura y evolución.
- Gráficos personales por fecha.
- Estadísticas agregadas y anónimas por región, periodo y síntoma.
- Separación estricta entre datos identificables y métricas agregadas.

## Alcance del MVP
1. Fiebre.
2. Dolor de cabeza.
3. Golpes leves.
4. Reglas de derivación urgente.
5. Panel personal de evolución.
6. Panel agregado con tamaño de muestra y advertencia de representatividad.

## Principios
- La información médica debe tener fuente, fecha de revisión y responsable.
- Los datos de salud son sensibles: consentimiento explícito, seguridad, acceso y eliminación.
- No se mostrarán resultados agregados con grupos demasiado pequeños.
- Las imágenes serán material de referencia, nunca diagnóstico automático.
